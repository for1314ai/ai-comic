# 使用本机 Codex CLI 生成漫画

此本地改造版把文字和图片生成都接入 `codex exec`，沿用 CLI 的 ChatGPT 登录。
无需填写模型名称、API 地址或 API Key。请使用本机启动方式；原项目 Docker 镜像不包含 CLI 和登录环境。

## 启动

1. 安装 Codex CLI，执行 `codex login`，通过 ChatGPT 登录。
2. 安装项目依赖：在 `server` 和 `web` 目录分别执行 `npm ci`。
3. 在 `web` 执行 `npm run build`，把 `web/dist/` 的内容复制到 `server/app/public/`。
4. 在 `server` 执行 `npm run start:codex`。
5. 打开 `http://127.0.0.1:7001`，注册本地漫画账号，创建短篇或连载。

首次启动会自动为尚未配置提供商的文字、图片类别创建 Codex 默认项。
已有模型配置不会被覆盖。此版本只改动后端，已有后台表单中的 API 字段对 Codex 不生效，正常创作无需进入该表单。

## 行为与范围

- 文字生成返回结构化结果，兼容剧情优化、分镜、续写和表单辅助。
- 图片生成调用 CLI 内置 `image_gen`，同时传递本地角色、风格与上一页参考图。
- 生图结果复制为 PNG 后交回原有保存、预览和 PDF 流程；不使用 SVG 或占位图替代。
- 调用使用 CLI 默认模型与 `--ignore-user-config`，保留已保存登录；不修改全局配置。
- 请求在服务进程内串行执行，每个 CLI 任务最多等待 10 分钟；正常完成或报错后会清理临时工作目录，强制退出可能留下临时文件。
- 原始生图结果可能仍保存在 Codex 自己的 generated_images 目录，应用不会删除它们。
- 尺寸作为生成提示传入，内置工具不保证精确像素尺寸；人物一致性依赖参考图及生成效果。
- 使用现有账户权益和限额，并非无限免费。若限额、网络或登录失败，应用返回错误，不切换付费 API。
- 这是本机个人使用入口，只监听 127.0.0.1。不要把可执行本机 CLI 的服务公开到互联网。

## 测试

在 `server` 目录执行 `npm test`。Codex 适配器单元测试使用模拟进程，不消耗模型额度。
真实生图验证需要已登录的 Codex CLI 和网络，且会使用账户额度。
